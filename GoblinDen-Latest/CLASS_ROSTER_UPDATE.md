# Four-class roster update

## Recommended structure

The player directly controls one Goblin specialist at a time and can freely try all four classes in the den. Recruited core classes fight as AI companions. This preserves a clear player character while still allowing a complete four-Goblin squad.

## Trying classes

- **1** — Blade Goblin
- **2** — Archer Goblin
- **3** — Knight Goblin
- **4** — Mage Goblin
- **E at the Training Pit** — cycle to the next class
- **C** — cycle the active class's unlocked evolution

Every class has its own character painting, attributes, basic attack, projectile or melee behavior, and special ability.

## Squad behavior

The Recruitment Hut offers core-class companions other than the class currently controlled by the player. If the player switches into a class already represented by a recruited companion, that companion waits at the den. The previously controlled class can rejoin once recruited, keeping combat to one Blade, one Archer, one Knight, and one Mage at most.
